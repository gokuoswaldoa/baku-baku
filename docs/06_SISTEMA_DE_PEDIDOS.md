# Pedidos
Flujo: marca/producto → configurador → carrito → modalidad de entrega → datos → resumen → confirmación.
Modalidades: recoger en domicilio (sin envío) o entrega a domicilio (envío separado).
Datos mínimos: nombre y teléfono. Para entrega: calle/número, colonia/localidad, referencias y pin GPS.
Estados sugeridos: nuevo, confirmado, preparando, listo para recoger, asignado a repartidor, en camino, entregado, cancelado.
Panel administrativo: pedidos, detalle de personalización, modalidad, contacto, ubicación, estado e historial.
Pendiente definir métodos de pago y política de confirmación. No implementar pagos online sin aprobación. No publicar domicilio particular abiertamente sin decisión expresa.

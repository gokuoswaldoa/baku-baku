# Instrucciones para Antigravity
- Lee README, AGENTS y todos los documentos de docs antes de actuar.
- La documentación es la fuente de verdad. Señala contradicciones y pregunta.
- No recrees, deformes ni alteres el logo o mascota oficiales.
- Identidad: urbana, juvenil, enérgica, profesional y limpia.
- El producto son bolas de arroz rellenas y empanizadas, no makis ni nigiris.
- Prioriza móvil, accesibilidad, rendimiento y checkout sencillo.
- No inventes precios, tarifas, ingredientes ni cobertura.
- Protege datos personales y no expongas claves API en frontend.
- Primero presenta plan, arquitectura, modelo de datos, riesgos y pendientes. Espera aprobación antes de programar.
